# fuck-off-msg

安卓通知静默拦截 App。

当前分支实现了 MVP 骨架：

- 通知监听服务声明。
- 系统白名单、用户白名单、用户黑名单、默认营销词、增强营销词的规则引擎。
- 默认营销关键词词库。
- 历史页、应用页、规则页、设置页。
- 涂抹选词页：连续选择合并为一个词，非连续选择拆成多个词，添加后文字格子置灰且不返回。
- PowerShell UTF-8 中文输出配置。

本地构建使用 `E:\SDK\jbr17` 作为 JDK 17。Android Studio 正在导入项目时，不要额外下载 JDK；等待 IDE 同步完成后再运行 Gradle 测试和 Debug 构建。
